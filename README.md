# Renasci como Baú

RPG isekai de turnos em pixel art. Você morre na Terra e renasce como um mímico numa masmorra.

**Jogar:** https://andre-brito-py.github.io/isekai_bau/

No Android, abra o link no Chrome e toque em **⋮ → Instalar app**. O jogo ganha ícone na tela inicial, abre em tela cheia e funciona offline.

- `index.html`, `manifest.webmanifest`, `sw.js` e os ícones formam o app publicado.
- `fonte/` guarda o código-fonte (sprites, música, história e motor) usado para gerar o `index.html`.
